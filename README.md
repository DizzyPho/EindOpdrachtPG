# Meerkeuze Testapplicatie opzetten

Het opzetten van de applicatie is heel simpel. 

1. Ga naar SQL/scripts, daar vind je een script genaamd create_database.sql
2. Open dit script in SQL Server Management Studio en voer het uit
3. Vul je connectionstring in in MultipleChoiceSolution/MultipleChoiceGUI/Config/appsettings.json

Je bent nu klaar om de applicatie te gebruiken. Database-, klasse- en architectuurdiagrammen bevinden zich in de map diagrammen.
